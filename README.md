# 计算机词典刷题

给英语基础比较弱的计算机初学者用的术语词典和刷题应用。交互参考驾考宝典：一屏一题，选完才看对错和解析。

每个术语都会给出：

- 英文
- 汉字读音提示，例如 HTTP 「艾奇替替皮」
- 中文意思
- 白话解释
- 一句用法例句

界面文字都是简体中文。

## 在手机上用 Expo Go 运行

1. 电脑安装 [Node.js](https://nodejs.org/) 20 或更新版本。
2. 手机安装 **Expo Go**（应用商店搜索 Expo Go）。
3. 手机和电脑连同一个 Wi-Fi。

在项目目录执行：

```bash
npm install
npx expo start
```

终端里会出现一个二维码。

- Android：打开 Expo Go，扫描终端里的二维码。
- iPhone：用系统相机扫描二维码，再点提示，用 Expo Go 打开。

如果二维码扫了打不开，多半是手机和电脑不在同一个网络。可以改用隧道：

```bash
npx expo start --tunnel
```

## 在浏览器里看

```bash
npx expo start --web
```

浏览器会打开网页版。窗口比较宽时，页面中间会收成手机宽度。

## 怎么用

底部四个入口：查词、刷题、复习、我的。

- **查词**：边输入边出建议，支持英文模糊匹配和中文。搜索历史可以清空。词卡上有大词头、英音和美音朗读、汉字谐音、词性、中文意思、白话释义、两三条例句和中文翻译，以及可点的相关词。
- **生词本**：在词卡上一点加入。可以按加入时间或字母排序。
- **复习**：今天到期的生词用卡片背。认识、模糊、不认识分别对应艾宾浩斯间隔 1、2、4、7、15 天。认识进入下一档，模糊隔一天且不升级，不认识回到今天。「我的」页会显示今日待复习数量。
- **科目**：刷题页右上角和「我的」都能进入。科目库可以搜索，也能做几题后按水平推荐。点进科目再添加到「我的科目」，或点 ＋ 自建科目并录入术语，题目会自动生成。已添加的科目决定章节、模拟考试和复习里有哪些词。
- **刷题**：章节练习、模拟考试、错题本都还在。单选题四个选项，答完才显示对错和解析。错题要在错题本里连续做对 2 次才移出。
- **外观**：默认深色，可在「我的」或科目页切换。
- **评分**：答对加经验，章节答错扣爱心，错题本答对可以找回。每日目标和连续学习在「我的」。规则写在「评分规则」。本周排行里的对手是本机示例。模拟考试 90 分及格。
- **编程题**：在刷题页进入。每题有中文题面、样例、起始代码，可以在 JavaScript 和 Python 之间切换。运行只判样例，提交才判隐藏测试。没通过的提交会进错题本。题面里的英文术语可以点开词卡。

## 编程题怎么判

JavaScript 默认在本机运行，不需要网络，也不需要密钥。

Python 默认请求公开的 Judge0 实例 `https://ce.judge0.com`（不需要密钥，有频率限制，大陆网络不一定打得开）。连不上、限流或超时时，页面会说明这是判题服务的网络问题，不是应用坏了，并且这次不会记入错题本。题目列表上的「需联网」只表示 Python 要在线判题，JavaScript 仍在本机运行。要换成自己的 Judge0 或 RapidAPI，在项目根目录建 `.env`（不要提交）：

```bash
EXPO_PUBLIC_JUDGE0_URL=https://ce.judge0.com
EXPO_PUBLIC_JUDGE0_KEY=
```

只要自建了 Piston，再设置 `EXPO_PUBLIC_PISTON_URL`。公开的 emkc.org 从 2026 年 2 月起不再接受普通执行请求。改完环境变量后重新执行 `npx expo start`。
- **我的**：已学术语、正确率、连续学习天数、错题数、生词数和今日待复习。答对一次，这个术语就记入已学。

进度、错题和收藏都写在手机本地（AsyncStorage），不上传。

## 词库

内置示例词库，不是完整的计算机词典：80 个术语，每个术语 3 道题，共 240 题。数据在 `src/data/terms.ts`，题目由 `src/data/questions.ts` 按固定规则生成，刷新不会把选项顺序打乱。

检查数据：

```bash
npm run validate
npm run typecheck
```

## 打 iOS 安装包

内部试用包用 Expo EAS。需要 Apple Developer Program 和 Expo 账号。在项目根目录执行：

```bash
npx eas-cli build -p ios --profile preview
```

`preview` 打的是 Ad Hoc / 内部安装用的 IPA。证书、描述文件和 `.env` 里的密钥不要提交到仓库。步骤写在 [docs/ios-build.md](docs/ios-build.md)。

## 这一版没有做的

- 没有账号、登录和云同步
- 英音和美音用系统朗读（expo-speech），不是真人录音；汉字谐音仍然保留
- 不能导入自己的词库
- 没有间隔重复，错题只按「连续做对 2 次移出」处理
