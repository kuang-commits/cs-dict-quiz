# 计算机词典刷题

给英语基础比较弱的计算机初学者用的术语词典和刷题应用。交互参考驾考宝典：一屏一题，选完才看对错和解析。

每个术语都会给出：

- 英文
- 汉字读音提示，例如 HTTP 「艾奇替替皮」
- 中文意思
- 白话解释
- 一句用法例句

界面文字都是简体中文。

## 在手机上用 Expo Go 运行

1. 电脑安装 [Node.js](https://nodejs.org/) 20 或更新版本。
2. 手机安装 **Expo Go**（应用商店搜索 Expo Go）。
3. 手机和电脑连同一个 Wi-Fi。

在项目目录执行：

```bash
npm install
npx expo start
```

终端里会出现一个二维码。

- Android：打开 Expo Go，扫描终端里的二维码。
- iPhone：用系统相机扫描二维码，再点提示，用 Expo Go 打开。

如果二维码扫了打不开，多半是手机和电脑不在同一个网络。可以改用隧道：

```bash
npx expo start --tunnel
```

## 在浏览器里看

```bash
npx expo start --web
```

浏览器会打开网页版。窗口比较宽时，页面中间会收成手机宽度。

## 怎么用

底部有五个入口：首页、词典、练习、错题、收藏。

- **词典**：按分类浏览，也可以搜英文或中文。点进去看读音、意思、解释和例句，并能收藏。
- **章节练习**：网络、编程基础、数据库、操作系统、网络安全、Web。单选题四个选项，答完显示对错、正确答案和短解析。
- **模拟考试**：随机 20 题，限时 10 分钟。可以提前交卷，没做的题按答错计分。结束页有分数、正确率和错题列表。
- **错题本**：答错的题保存在本机。在错题本里重练，同一题连续做对 2 次后移出。中途再错，连续次数清零。在章节或考试里答对，不会把题移出。
- **首页**：已学术语、正确率、连续学习天数、错题数和收藏数。答对一次，这个术语就记入已学。

进度、错题和收藏都写在手机本地（AsyncStorage），不上传。

## 词库

内置示例词库，不是完整的计算机词典：80 个术语，每个术语 3 道题，共 240 题。数据在 `src/data/terms.ts`，题目由 `src/data/questions.ts` 按固定规则生成，刷新不会把选项顺序打乱。

检查数据：

```bash
npm run validate
npm run typecheck
```

## 这一版没有做的

- 没有账号、登录和云同步
- 没有真人发音，只提供汉字谐音
- 不能导入自己的词库
- 没有间隔重复，错题只按「连续做对 2 次移出」处理
